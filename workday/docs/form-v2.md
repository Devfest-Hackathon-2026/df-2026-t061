# 企業ヒアリング v2

フォーム冒頭の案内例：直近で覚えている「新人が判断に迷った1件」を、当時を知る方がお答えください。機密情報や実名は書かず、役割名をお使いください。

下表の太字を質問タイトルに、説明をフォームの質問説明に設定する。CSV見出しはタイトルと一致させる。Googleフォームのタイムスタンプなどの余分な列や、列順の変更は問題ない。任意欄は未回答でよい。

| 質問タイトル（列名） | 説明 |
|---|---|
| **企業名**・**職種**・**実話のタイトル** | それぞれ短文。タイトルは同じ職種のほかの実話と区別できる名前にする。 |
| **事業部・部署** | 任意。 |
| **新人への依頼と期限** | 何をしていたとき、誰から、どんな一言で、いつまでに何を頼まれたか。 |
| **判断前に分かっていたこと**・**まだ分からなかったこと** | 別々の段落質問。当時見られた資料や数字を匿名化して書く。 |
| **新人の裁量と相談できた相手** | 即決できたこと、承認が要ったこと、その時点で頼れた人。 |
| **行動A**・**Aで守りたいこと**・**行動B**・**Bで守りたいこと** | それぞれ短文。どちらも当時、新人が取り得た行動にする。 |
| **実際に選んだ行動** | 単一選択 A / B。Aを常に実際の行動にする必要はない。 |
| **実際の返事と次の仕事** | 誰からどんな返事が来て、何が次の仕事になったか。その日に結末が分からなければ、その時点まで。 |
| **別の行動の根拠** | 任意。単一選択「別の実例」「経験上の予想」「分からない」。空欄は「分からない」として扱う。 |
| **別の行動の続き** | 別の実例・予想のときのみ記入。不明なら空欄。 |
| **起こる頻度**・**誤解してほしくない点・例外条件** | 別々の質問。通常業務かまれな例か、条件が変わると別の行動が妥当になる例を聞く。 |

見本の1件目はAが実際の行動でBが予想。2件目はBが実際の行動でAは不明。修正した同じ実話の再取込は以前の承認を取り消す。別の回答にしたいときは異なるタイトルを使う。

## 同じチームの複数回答を使う実験

追加する列は **回答者コード** と **別の判断が妥当になる条件**。コードは社員名ではなく同じ回答者が使い続ける匿名の識別子。後者は「違う行動が適切になるとしたら、当時のどの条件が違うときですか？」と尋ねる。企業・部署・職種はいずれも埋め、同じチームの複数人から集めると判断の違いを扱える。アプリは取込時にチームごとに自動分類する。回答が1件だけでも試せる。部署が空欄の回答は別々に扱う。社員が実際に送信したかどうかを自動認証する機能はない。
